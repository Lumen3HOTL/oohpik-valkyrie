Dragonfly egg++ implementation
a variant of dragonfly egg written in c++ 20 exclusively for windows with a few extra features and customisations. it should be more or less backwards compatible with dragonfly, but has som extra functionality to make development nicer, and some changes on the back end for performance

to build, open the visual studio solution file in visual studio and build the code. to run the tests, just run the exe, the tests are set up to run automatically, and log their results to dragonfly.log automatically. additonally, final graphics tests may be interacted with by pressing keyboard keys, moving the mosue, and pressing mouse buttons.
