# AI Usage
So far, this project has seen minimal AI use. Because its test suite has not been properly updated,
the primary AI use has been to help diagnose and resolve issues regarding the Visual Studio project and difficulty
getting the repository to conveniently work between the two of us. Namely, Claude was used to help resolve
issues due to differences in where SFML was placed in the file structure in a way which was not able to be conveniently
changed externally, leading to the AI proposing the multiple-check idea and aiding in its implementation. Besides that,
it was mostly using AI as the most convenient tool to fix out of date Visual Studio project and filter files caused by
both user error and version control issues when it wasn't able to be resolved by hand without significant time and effort.

AI will likely see a more intense use in the project as it is used to implement the test suite, as in the process it will
likely discover existing issues which we had not caught (speaking from previous experience).
